# Shopify CLI store auth

Authorizes Shopify CLI to read and write store data (products, content, themes, translations, …) on `h80p2u-8v.myshopify.com`. Run it once per machine, or again when the scopes change.

```sh
shopify store auth --store h80p2u-8v.myshopify.com --scopes read_orders,write_orders,read_order_edits,write_order_edits,read_fulfillments,write_fulfillments,read_fulfillment_constraint_rules,write_fulfillment_constraint_rules,read_shipping,write_shipping,read_delivery_customizations,write_delivery_customizations,read_legal_policies,write_legal_policies,read_draft_orders,write_draft_orders,read_payment_terms,write_payment_terms,read_payment_customizations,write_payment_customizations,read_gift_cards,write_gift_cards,read_gift_card_transactions,write_gift_card_transactions,read_store_credit_accounts,read_store_credit_account_transactions,write_store_credit_account_transactions,read_shopify_payments_accounts,read_shopify_payments_bank_accounts,read_shopify_payments_disputes,read_shopify_payments_payouts,read_products,write_products,read_product_listings,read_publications,write_publications,read_purchase_options,write_purchase_options,read_resource_feedbacks,write_resource_feedbacks,read_discounts,write_discounts,read_price_rules,write_price_rules,read_validations,write_validations,read_cart_transforms,write_cart_transforms,read_inventory,write_inventory,read_inventory_shipments,write_inventory_shipments,read_inventory_shipments_received_items,write_inventory_shipments_received_items,read_inventory_transfers,write_inventory_transfers,read_locations,write_locations,read_markets,write_markets,read_returns,write_returns,read_cash_tracking,write_cash_tracking,read_customers,write_customers,read_companies,write_companies,read_customer_data_erasure,write_customer_data_erasure,read_customer_merge,write_customer_merge,read_content,write_content,read_online_store_pages,write_online_store_pages,read_online_store_navigation,write_online_store_navigation,read_themes,write_themes,write_app_proxy,read_privacy_settings,write_privacy_settings,read_checkout_branding_settings,write_checkout_branding_settings,read_checkout_and_accounts_configurations,write_checkout_and_accounts_configurations,read_script_tags,write_script_tags,read_pixels,write_pixels,read_customer_events,read_files,write_files,read_metaobject_definitions,write_metaobject_definitions,read_metaobjects,write_metaobjects,read_locales,write_locales,read_translations,write_translations,read_marketing_events,write_marketing_events,read_reports,write_reports,read_analytics_annotations,write_analytics_annotations,read_rollouts
```

A `write_` scope also grants read access. Available scopes: [Shopify access scopes](https://shopify.dev/docs/api/usage/access-scopes).
